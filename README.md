# Caxeta

App PWA para contar pontos de Caxeta (regras do Paraná). Vite + React + TypeScript.

## Comandos

```
npm install        # instalar dependências
npm run dev        # rodar local (acessível na rede)
npm test           # testes (Vitest)
npm run build      # gera a pasta dist
npm run preview    # testar o build local
npm run icons      # regenerar ícones em public/
```

## Cloudflare Pages

- Build command: `npm run build`
- Build output directory: `dist`
- Node: 20 ou superior
